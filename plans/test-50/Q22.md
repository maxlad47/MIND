Cible M22 (3 séance(s)) : prioritaire 12-16, secondaire 6-8.

**Ce que les règles ont décidé ou signalé**
- **E1** : jour de sortie longue dimanche hors des jours choisis → jeudi (formulaire)
- **E4** (bloquant) : 4 sorties pour 3 jours : le formulaire bloque à 3 (J4)
- **J6** : jour(s) doublé(s) supposé(s) choisi(s) par l'utilisateur : lundi, mercredi, jeudi
- **M13** (conseil) : minimum prioritaire non atteint (biceps 4/12, épaules 7/12, quadri 8/12) → moins de prioritaires ou une séance de plus
- **M22** (conseil) : secondaires sous leur cible : pecs 0, dos 3, triceps 0, ischios 0, fessiers 0, mollets 0, abdos 0

**Avis de coach** — Course propre (3 sorties, un seuil court). La muscu est trop ambitieuse pour 30 min : 3 prioritaires en force + esthétique, c'est M13 assurée et des séances de 2 exercices. Trois jours tous doublés pour un débutant en muscu, c'est lourd.
