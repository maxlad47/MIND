## R46 — Pas de course (muscu seule), aucune course, hypertrophie × 6

*Muscu seule, 6 séances, push / pull / jambes × 2.*

| | Profil | Proposition |
|---|---|---|
| **Course** | Pas de course, « muscu seule ». aucun chrono, régulier. Sorties : 0, 0. | Muscu seule (E7) : aucune règle de course. |
| **Muscu** | Hypertrophie, 6 séance(s), confirmé, salle, push / pull / jambes. Prioritaires : épaules, fessiers. Renfo coureur décoché. 10 traction(s) stricte(s). | 6 séance(s), push / pull / jambes (M26). 8-12 reps, ~2,5 min par série (M23). |
